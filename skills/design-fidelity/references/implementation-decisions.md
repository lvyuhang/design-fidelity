# 节点实现决策

`generate` 已按下表为每个节点做出确定性处置，并写入 codegen 报告。只有在复核 `unsupported`、`issues`，或用 override 改写某个节点时才需要读本文。依据始终是 MCP 原始数据，名称和截图观感不能替代证据。

| 源证据 | 生成器处置 | 需要你做的 |
|---|---|---|
| 已导出原始位图/SVG | `SourceAsset`，按 export frame 放置，保留透明边距 | 素材包含装饰文字时不重复实现那部分文字 |
| 完整矢量路径 | `SourceBox` + `SourcePathShape` | 逐顶点圆角会被标为 unsupported，需要原始导出 |
| 照片、头像、业务图标等无素材 | `SourcePlaceholder`，保留外形与效果 | 向设计索要导出；单项源渲染回退须用户授权 |
| 阴影、模糊、渐变、透明叠层、遮罩 | 对应原语，scene 测试绑定源参数 | 复核报告中的 unsupported |
| 状态栏 / Home Indicator | 系统 chrome，只占位不绘制 | 无 |
| 类型或参数无法确定 | 报告为 issue | 补取证据，记录未实现原因 |

无 asset_id 不等于缺图，先查完整原始矢量和效果。不能根据零散路径仿造定制素材，也不能用 `Icons.*`、emoji 或箭头字形代替（lint 会拦截）。不得把带业务文字、按钮、状态或导航的区域打平成截图；缺照片也不意味着整张卡片都可以截图。

## 几何

子节点局部坐标等于 child.bounds 减去 parent.bounds；父级水平/垂直翻转由生成器用 `Transform.flip` 作用在父容器上，子路径随之镜像，不要再手动换算。三种画框各有用途：layout frame 放组件，export frame 放带透明边距的素材，ink frame 用于检查可见轮廓。不要用 `BoxFit.fill` 把素材压进布局框，也不要裁掉透明边距来凑尺寸。

## 复合行与动态文字

生成的 Scene 是绝对定位，适合还原；遇到会随数据变化的区域，用 override 改写为弹性布局：

- **同行关系**：同一基线、相邻且语义相关的名称、标签、计数按一行实现。先从节点画框计算 `gap = trailing.left - leading.right`，主文字用 `Flexible` 单行并在运行时省略，标签、图标、计数保持源固定画框。只有源文案本身含省略号时才保留字面省略号。
- **宽度来源**：整行宽度取"父容器可用宽度减去右侧保留槽"，不要用当前短文案与尾项的 union bounds。设计稿有长文案样例时，用它的文本框定义主文字上限。
- **溢出反例**：至少用超过可用宽度的名称跑一次组件测试，断言主文字不越过尾部控件，且间距仍等于源测量值。多尺寸门禁会在 1.3 倍字体下报告文字重叠。

## 透明叠层与背景

- 从整页提取导航、浮层或蒙版时，页面根背景不属于可复用叠层。叠层默认透明，只在独立预览壳里注入画布背景。
- 缺图会改变背景频率和混色基底。照片占位不能成为反向移动渐变停止点或调透明度的理由；受缺图影响的合成区域要单独披露。
- 先实现结构（容器、遮罩、背景效果、跨边界叠层），再填照片、文字等内容。有素材的异形底片不会因同区域照片缺图而消失。

## 浅色大面积背景的色偏

修代码前先固定选区：每个容器的顶部、中部、底部和左右内部空白处，避开文字和图标。逐区报告原稿与实现的 RGB、每通道有符号偏差、MAE 和 P95，不能把不同区域合并抵消。`scripts/background_bias.py` 接收原尺寸图片和像素选区 JSON。定位时用控制变量：源底色 → 纯 alpha 合成 → 逐个启用效果 → 完整场景。只修能证实的映射；平台补偿必须标注校准和适用渲染后端，不能偷偷改源颜色。
