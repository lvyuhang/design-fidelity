# 节点实现决策

仅在确定实现方式或定位素材/几何问题时查阅。依据 MCP 原始数据，名称和截图观感不替代证据。

| 源证据 | 处置 |
|---|---|
| 可导出原位图/SVG/bundle | 使用原资源，保留透明画框、缩放与裁剪 |
| 通用界面矢量且数据完整 | 按源路径/变换/填充/描边精确绘制 |
| 定制照片、头像、印章、业务 icon 等无素材 | 按用户策略；默认保形占位，标记未切图 |
| 下划线、色带、引号底板、分隔线 | 独立节点实现与检查，不合并到文字后遗漏 |
| 阴影、发光、模糊、渐变、透明叠层 | 保留源参数、父组效果、叠层和裁剪 |
| 类型/参数无法确定 | 补取证据，记录未实现原因 |

无 asset_id 不等于缺图；继续查完整原始矢量/效果。定制素材不能根据零散路径仿造。仅获授权时，单个静态素材可用源渲染回退并记录节点和画框。不得把带业务文字、按钮、状态或导航的区域打平；缺照片不意味着整张卡片都可截图。装饰字形回退需 static_artwork_reason 说明，不能用于业务标签。代码绑定与实际素材内容仍需复查，声明本身不是证明。

## 几何

先固定父级源画框，用 child.bounds−parent.bounds 得局部坐标。归一化点按源 width/height 映射；保留贝塞尔控制点、旋转/翻转、复合路径/填充规则、线宽、strokeCap/Join、祖先裁剪。不能只连端点、改成框架 icon 或靠移动父级补偿子级误差。

源画框用于布局，透明墨迹与组合关系用于视觉检查。描边外扩应纳入 ROI；不能裁掉以让 bbox 相等。Flutter 小矢量仅在完整源路径、父变换、描边和填充均已取证时使用固定源尺寸 CustomPainter，并在 `graphics_provenance` 绑定 node_id 与几何 pointer。熟悉的垃圾桶、回复气泡、箭头仍属于定制视觉：缺 asset_id 且路径不完整时使用同画框占位，不能目测仿画、使用 `Icons.*` 或 Unicode/emoji 代替。避免 IconButton 默认 padding、最小尺寸和主题注入，触控热区可独立外包。

`scripts/graphic_source_audit.py` 扫描实现输入中的 `CustomPaint` 和框架图标。`source_vector` 绑定必须指向源 evidence 中实际存在且非空的几何；`system_chrome` 仅用于平台状态栏并填写理由。未绑定、失效或残留绑定均失败。完整契约由 `run_flutter.py` 自动执行；轻量案例显式传 `--source`、`--root` 和 provenance 文件，报告随运行日志保存。

## 复合行与透明叠层

- **同行关系**：同一基线、相邻且语义相关的名称/标签/计数按一组实现。先从节点画框计算 `gap = trailing.left - leading.right`；重复实例一致时固化为组件参数，不把子项各自绝对定位。主文字用 `Flexible`/等价约束、单行与运行时省略；标签、图标和计数保持源固定画框。数据中只有源文案真的包含省略号时才保留字面省略号。
- **溢出反例**：至少用超过可用宽度的名称运行一次组件测试，断言主文字右边界不超过尾部控件左边界，且间距仍等于源测量值。只检查默认短文案不能证明组件成立。
- **宽度来源**：复合行整体约束取“父容器可用宽度减去右侧保留槽”，不要把当前短文案和尾随元素的 union bounds 当成最大宽度；设计工具与运行时字体度量相差不足 1 px 时，后者会让合法短文案提前省略。设计稿有长文案样例时，用其文本框定义主文字上限。例如 11 px 中文的 55 px 名称槽允许 4 个全角字再加省略号，同时必须保证三字名称完整显示。
- **叠层背景责任**：从整页提取导航、浮层或蒙版时，页面根背景不属于可复用叠层。叠层默认透明，只在独立预览壳明确需要时注入画布背景；不能把根背景和半透明渐变同时封装，否则透明 stop 会在不透明底上退化。
- **透明机制测试**：将实际叠层分别放在两种高反差底色或条纹上，检查透明端保留底层差异、实色端按源 alpha 收敛。整页白底截图无法证明透明度与渐变正确。

## 缺图占位

外形/尺寸遵循源素材：圆形头像仍为圆形，圆角保留圆角，复杂轮廓依据源路径。默认底色 #FFE5EA、描边 #FF4D6D、文字 #C52245，语义提示“设计素材未切图”；项目已有统一样式可复用。占位不能改变相邻布局。

主契约保持原参考图，精确排除无法比较的素材内部，逐项记录原因；周围边框/间距仍检测。用 Widget 断言或明确标注的合成契约验证外形，不把占位通过说成素材还原通过。

## 合成关系先于内容

画面由形状、内容、绘制顺序、裁剪范围和底层背景共同决定，节点数量完整不代表合成正确。prepare 自动列出 `scene_requirements`：背景模糊、mask，以及跨越 mask 边界的后绘制素材。它是源关系提示，不自动认定某个形状该用布尔镂空还是盖片；保留源层级，检查局部原图/单个素材后决策。未命中自动规则的复合路径或叠层仍需人工补查。

- 先实现结构：容器/遮罩 → 背景效果 → 跨边界叠层；照片/文字等内容随后填入。有素材的异形底片不因同区域照片缺图而消失，也不能被错误放入照片裁剪中。
- 背景模糊检查填充 alpha、源半径到渲染器单位的映射、背景输入和 clip 范围。`BoxShadow.blurRadius` / 前景模糊不能替代背景模糊；源 radius 不默认等于 Flutter sigma，转换须有证据或明确标注校准。
- 占位会改变背景频率；单色底下无模糊也可能像素通过。测试实际组件在黑/白与高频条纹背景上的响应：透明度控制背景透出量，模糊应衰减细节，裁剪外不受影响。合成测试只证明机制，原稿局部检查仍负责参数/最终外观。
- 跨边界叠层检查源资产、完整 export frame、相对位置、绘制顺序、裁剪祖先与可见轮廓。原图已提供盖片时用原片，不从“镂空”的口头描述推导一个近似圆洞。照片占位也保留盖片/负空间局部检查。

在 reviewed spec 中按同类组件绑定 `scene_checks`，合并到一个测试命令，勿为每个节点启动 Flutter。源码值从固定证据读取，测试调用生产组件；测试新建/修改时确认删掉效果/盖片会失败。测试文件和生产文件都加入 implementation_inputs。字段见[契约字段](visual-contract.md#scene_checks)。不能用 `assert True`、只检查源码关键字、手写通过收据或缩小到未受影响区域来代替测试。

## 效果问题

排查顺序：源/祖先样式→实现→裁剪遮盖→测试阴影开关→单位/DPR。MCP 参数缺失先补取；确实无法取得而按参考图校准时标记推导来源，并用局部效果检查验证，不能称 MCP 精确提供。不完整定制素材仍按占位规则处理。采样位置和检测字段仅在 visual-contract.md 定义。

## 渲染语义验证

对本页实际出现的语义检查，按类批量执行；不要追加项目专属尺寸清单。

- **三个画框**：layout frame 放组件，export frame 放带透明边距/描边/阴影的整张素材，ink frame 检查可见轮廓。核验导出密度、原始像素尺寸、导出原点与源坐标映射；effective_density=像素/布局宽不是原始导出密度的证明。未验证映射时标 unresolved，不用 `BoxFit.fill` 强行压进布局框，也不裁透明边距来凑尺寸。测试应同时检查图标墨迹宽高及相对位置。
- **描边位置**：内、居中、外描边不可共用居中实现。以纯色圆/圆角框测试填充边界、描边外沿及裁剪；例如直径 d、外描边 t，填充仍为 d、外沿为 d+2t。用源参数推导期望，不能只断言 Widget 为 d。
- **阴影**：有 shadow 字段不代表效果正确。源 blurRadius 到渲染器 sigma 的转换须校准；记录 spread、offset、alpha 和裁剪。检查形状外侧的亮度/颜色衰减曲线，分别定位未绘制、被裁剪和强度/扩散错误。移除阴影的反例应失败；不得通过任意加深颜色补偿未知核。
- **半透明渐变**：固定源 from/to、stops、父变换和背景输入。照片占位会改变合成颜色与模糊输入；不能据此反向移动渐变停止点。先在同一黑/白/高频背景上测实际组件的透出与模糊，再对原稿可比区域检查。缺图影响的合成区域标依赖阻断，不能只排除照片本身后宣称卡片通过。
- **能力检查**：声明按语义细分（asset.export_frame、borders.position.*、shadow.kernel_and_extent、gradient.coordinates/background_dependency、blur.radius_mapping/saturation）；只声明 color/linear/blur 不足以覆盖。声明检查依然不执行测试，必须由 scene_checks 运行生产组件行为检查并绑定当前代码。

页面配置必须记录 renderer_kind、能力文件、检查范围和未解决项。裸运行截图/分析/构建只能产生 diagnostic_preview；不能省略页面配置后把“Skill 版本”标签当成已执行流程的证明。复用实现但没有行为验收记录时，视为未验证能力，而不是可信基线。


### 浅色大面积背景的色偏

选区在修代码前固定：每个容器的顶部、中部、底部和左右内部空白处，避开文字/图表/标签但不能仅取最接近原稿的边缘。逐区报告原稿/实现 RGB、每通道有符号偏差、MAE 及绝对差 P95；不能合并不同区域抵消偏差。`scripts/background_bias.py` 接收原尺寸图片及像素选区 JSON（regions: 名称→[x,y,right,bottom]，threshold: 每通道均值/P95 最大偏差）；阈值按任务预先确认，此脚本不是整页门禁。轻微单通道偏移覆盖大面积时仍可能显著，不能以三通道平均小于 1 自动忽略。

定位用控制变量：源底色→无阴影/模糊的纯 alpha 合成→分别启用效果→完整场景。用已知底色验证合成方程及输出量化，区分源参数、颜色空间/舍入和背景依赖。实验输出独立保存，恢复生产数据；诊断时刻意移除效果导致原断言失败要记录为预期控制实验，不能算生产通过。仅修复可证实的映射；为当前平台补偿必须标注校准及适用渲染后端，不能偷偷改源颜色，也不能把远离缺图的偏色泛化为缺图问题。
