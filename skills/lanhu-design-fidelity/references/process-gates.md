# 流程问题定位

仅在审计、连续无改善或门禁与肉眼结果冲突时使用；日常约束见 SKILL.md。

| 症状 | 先核对 | 处理 |
|---|---|---|
| 资源下载齐却漏底纹/引号/星光 | 完整分页、无 asset_id 叶节点、父级效果 | 补取并逐项处置；资源数不能代替节点覆盖 |
| 颜色/阴影反复凭感觉调 | raw_style、文本 run、祖先蒙版 | 定向 inspect，再用源参数实现 |
| 修一处影响其他区域 | 父画框、相对坐标、透明边距 | 固定父级后换算 child−parent，移除互相抵消偏移 |
| 整页通过但细节错误 | ROI、small_visual、效果采样、分割污染 | 用错误样本校准检查；保留旧基线，另立校准记录 |
| 两轮通过却无视觉变化 | 实现/契约差异、截图哈希、检查范围 | 区分实现修正与验收改动，局部通过不能算整页收敛 |
| 模型或流程质量差距异常大 | 冷/热启动、starter、源遍历、缺图策略、阈值是否一致 | 判为不可归因；按公平实验冻结条件后重跑 |
| 生成页仍漏复合图标或效果 | codegen 报告的 unsupported/issues；可见 shape 是否有路径或原素材 | 输入未闭合就阻断；补路径/原素材/已审核回退，重新 prepare → generate |
| 几何门禁通过但像素失败 | 效果参数、素材、字形渲染 | 局部区域定位，不改阈值 |
| 几何门禁失败集中在文字 line box | 字体文件、字重映射、行高、strut | 先修字体映射，不缩放文字迎合指标 |
| 1.3 倍字体下文字重叠或越界 | 绝对定位的文字组 | 用 override 改写为 Row/Column + Flexible |
| 用户名与状态标签在长文案时重叠 | 是否把同一基线子项分别绝对定位、是否把省略号写入动态数据 | 恢复为测量间距的复合行；主文字弹性截断、尾部固定，并加入长文案几何测试 |
| 短用户名被提前省略 | 是否用当前短文案与标签的 union bounds 作为整行最大宽度 | 从父容器可用空间和右侧保留槽推导整行宽度；用长文案样例定义主文字上限；同时测试短名完整显示与长名不碰撞 |
| 半透明底栏看起来是纯白蒙版 | 可复用叠层是否错误携带整页根背景；透明 stop 是否在对比底色上仍能透出 | 分离 root/background ownership；在两种底色上测试实际叠层后再跑原稿区域门禁 |
| 测试通过但肉眼差异明显 | 测试是否只检查组件存在、尺寸或数据绑定 | 保留结构测试作诊断，增加真实渲染的整页与区域像素门禁 |
| 第三轮仍失败 | 证据缺口、素材策略或坐标模型 | 保持未完成，换取证/回退策略 |

脚本可验证源身份、已提供节点、字段义务、哈希及声明的像素检查；不能自动证明 MCP 没有漏取、素材语义正确、运行时用了声明字重，或最终复查已完成。支持边界见 preparation.md。检测器维护与回归评估见仓库的维护者文档 `docs/maintainers/`。
