# LayerPilot 图层助手 0.5.7

只提供 **自动整理图层** 和 **自动切片** 两个菜单。运行时不联网、不调用 AI、不加载模型，也不需要 Node 或 API Key。目标版本为 Sketch 2026.1 及以上；本机测试版本为 Sketch 2026.1.1。

## 安装和流程

解压 `dist/LayerPilot-0.5.7.zip`，双击 `LayerPilot.sketchplugin`。在 Sketch 的 Plugins → LayerPilot 图层助手中使用两个功能。窗口标题应显示 **0.5.7**。

选中画板或内容区域 → 自动整理图层 → 自动切片 → 保存 Sketch 文档 → 使用蓝湖插件上传 → 研发在蓝湖按需下载。

有选区时只处理选区及后代；没有选区时处理当前页面。插件不会代你上传蓝湖，也不把切图文件导出到本地目录。所有修改可以使用 Sketch 的 ⌘Z 撤销。

## 0.5.7 分组边界与异步整理

- 整理命令改为真正的异步阶段调度，菜单回调先返回，再由计时器推进各阶段，使用 [Sketch fiber](https://developer.sketch.com/plugins/javascript-environment) 管理生命周期。整理过程不再走嵌套事件循环，不拦截或重放鼠标键盘事件。仍在主线程访问 Sketch 图层，单次快照或像素验证可能短暂停顿。
- 读取快照按不可变模型缓存；未改变的子树不重复读取。阶段间允许浏览画布及操作其他文档；检测到当前页面内容变化后停止任务，不强行继续覆盖。检测包含结构、名称、文字、几何和样式，不能保证覆盖所有插件或原生路径编辑操作，运行时仍建议只浏览当前稿。
- 以目标文档的历史合并保留一次撤销，取消/失败均释放状态条、任务锁和历史合并。该历史接口已在本机 Sketch 2026.1.1 验证；未来版本需要回归。
- 先以全画板背景/遮罩的层叠边界隔离弹窗区域，防止弹窗文字被底层信息流卡片收走。边界上有锁定、蒙版等不确定结构时不强行合并。
- 在隔离出的弹窗内，可重建插件生成的无样式旧区域组；保留手工组和有变换/样式的结构。重复的小型控件可吸收其正上方唯一且不属于其他卡片的标题，避免“男生”被归进“女生”的控件。
- 原生回归覆盖复杂弹窗分组、像素一致、重复运行、异步返回、其他文档持续响应和一次撤销。用户原稿只读，真实稿验证使用副本。

仍需人工走查实际鼠标和触控板手感。自动切片暂时沿用同步检查点流程，本次异步改造针对整理图层。以下章节是历史版本行为，涉及整理输入拦截的说明已被本版取代。

- 可以滚动画布和操作其他独立文档窗口。

- 不支持一边继续自动分组、一边手动修改相同图层。一次原生渲染期间仍可能短暂停顿。
- 完成后的详细统计、错误说明仍为结果面板；本次缩小的是运行过程提示。
- 原生测试检查无 sheet、尺寸、焦点、窗口归属、其他文档交互、安全停止和输入队列清理。屏幕交互权限未开放，鼠标拖动、触控板操作及提示位置的实际观感尚待人工走查。

## 0.5.5 的归组过程反馈

整理设置新增默认开启、可记住选择的「显示归组过程」。通过 Sketch 原生选区轮廓依次呈现待归组元素和成功创建的新组，进度文字同步显示阶段，图层树随实际结构更新。使用轮廓切换，不移动设计稿，不新增辅助图层，不调用 AI。

- 图标组合、内容区域和相邻元素三条分组路径均接入；需要像素验证的分组，只有验证成功后才显示完成反馈。
- 每组成员停留约 120 ms，新组约 180 ms；额外停留预算最多 2.4 秒（约前 8 组），后续继续普通进度，避免大文档逐组等待。可关闭显示过程。
- 不自动缩放或滚动画布，屏幕外的元素不会被强制拉入视野。原生选区样式由 Sketch 决定，当前文档 sheet 可能遮挡画布的一部分。
- 正常完成、停止或异常均恢复原选区；其他独立文档窗口仍可响应。
- 全套原生回归通过，包括新视觉事件与真实选区一致、停用开关、停止恢复、画面渲染一致和一次撤销。当前没有电脑交互权限，尚未完成屏幕动画观感走查；原生状态测试不等同于动画流畅度验收。

## 0.5.4 的窗口交互修复

- 按用户确认的范围，整理期间仅暂停正在处理的文档窗口编辑；其他独立 Sketch 文档窗口可以操作。一个窗口中的多个标签页仍属于同一个窗口，不能保证相互独立；请使用独立窗口。
- 进度改为附着目标文档的 sheet，移除应用级模态锁。普通 AppKit 事件循环在检查点处理其他窗口的输入。
- 运行期间切换窗口不会改变任务目标；整理和切片继续针对启动时捕获的文档与选区。
- 结果、空结果和错误提示也使用目标文档的 sheet，避免任务完成后又弹出应用级模态框。结果面板使用 Sketch fiber 保持按钮回调有效，关闭时释放。
- 点击插件命令时若已有任务运行，直接提示，不再打开第二个设置窗口。
- 回归验证包括：目标窗口有 sheet、另一窗口没有 sheet、运行时不存在应用级 modal window、另一测试文档在整理中响应操作、结果打开后其他文档仍可响应、关闭后解除保护、一次撤销还原。

本实现仍在主线程修改 Sketch 文档。长循环保留刷新点，但一次原生渲染仍可能造成短暂停顿；不能表述为完全后台或多线程整理。电脑交互权限未开放，本轮使用原生控件事件测试，未完成真人鼠标走查。

## 0.5.3 的刷新与过渡修复

- 修复“进度窗口存在，但计算期间仍像卡住”的问题。除了分派已排队输入，每次更新还给模态运行循环留出短时间处理绘制、计时器和动画提交。开始阶段先处理一轮绘制，再读取图层。
- 嵌套图层快照、切片预检查、像素数据转换和像素比较增加刷新检查点。刷新点只更新界面；停止仍在安全边界抛出，保持单次撤销。
- 识别资源后，在 loading 内准备候选列表，避免关掉 loading 后再静默创建大量复选框。
- 结束时显示短暂“处理结束／正在打开下一步”过渡；快速任务窗口至少显示约 220 ms，普通任务结束态保留约 120 ms。
- 本机同一份 120 图层诊断夹具：最长进度回调间隔从 1061 ms 降至 80 ms，耗时从 1787 ms 变为 1934 ms。这是特定夹具的时序数据，不代表任意设计稿，也不是屏幕帧率。

电脑交互权限未开放，本轮无法完成屏幕动效与鼠标流程验收。已补充原生运行循环计时器测试、停止与撤销回归；不再仅用“窗口可见”断言流畅。

## 0.5.2 的体验改进

- 识别、整理、画面核对和创建切片均显示运行窗口；展示当前图层、实际处理数量和已用时间。整理总工作量会随新增组变化，因此使用阶段提示，不显示虚假的整体百分比。
- 支持“停止”和 Esc。在安全边界停止，保留已完成部分，恢复原选区。单次原生渲染或当前区域校验不能立即中断；会在该步骤完成后响应。仍在同一 Sketch 命令内运行，完成或中途停止后可用一次 ⌘Z 撤销。
- 执行期间禁止重复启动。成功、停止和异常都会关闭运行窗口、释放运行状态。
- 切片候选列表增加全选／全不选及已选数量；空选禁用执行，PNG 倍率错误在当前窗口提示并保留勾选。仅选 SVG 图标时不再要求 PNG 倍率。
- 记住整理选项、分组间距、切片倍率、SVG 和图标画布设置；资源勾选不跨文档记忆。
- 结果区显示耗时，区分完成、停止、无需变更和部分失败。未修改时不再提示撤销，避免误撤销用户之前的操作。错误列表完整滚动显示，可复制全部结果，也可选中未处理图层并定位第一项。

## 0.5.1 的变化

- **自动选择标准尺寸**：默认从 16 / 24 / 32 / 48 / 64 中选择。先按图标自身几何尺寸加 4 px 总留白确定档位，再确保描边、阴影等实际绘制范围完全装入。小型播放三角、点赞图标使用 16 × 16；18–20 px 的导航图标通常使用 24 × 24。不会因为按钮底板或旧 Slice 边框而撑大画布。
- **避开文字**：在页面坐标中检查周边可见文字，包括选区外和锁定的文字。自动档若发生重叠，尝试能够容纳图标的更小标准档；仍放不下则跳过并提示。手选固定尺寸同样检查重叠。跳过时已有切片保持原样，需要用户单独调整。
- **旧切片直接更新**：选中本插件生成的 Slice 也能重新计算源图标；兼容正式安装插件与本地验证副本的资源关联。更新现有切片，不重复添加。

## 0.5.0 的变化

- **多级整理**：先归拢区域，再继续细分图标和文字、重复列表项、局部内容。旧版插件生成的区域组也能继续整理；不会每次重复套组。导航项按现有文字命名，不推测业务含义。
- **完整卡片**：归组时同时考虑卡片底板、图片、文字和已有内容组。隐藏的普通装饰层不再被误认为可见遮挡。蒙版、锁定层、自动布局和特殊混合结构仍受保护。
- **图标去按钮底色**：识别简单实心圆形/矩形底板与较小的居中矢量图标；例如通知按钮只切铃铛、播放按钮只切三角。描边外圈、任意复杂轮廓不会被直接当作按钮背景。
- **统一画布**：图标默认 SVG，0.5.1 起默认自动选择标准尺寸，也可手选 16 / 24 / 32 / 48 / 64。图标居中保留透明留白，不缩放原图；含描边和阴影的实际范围放不下时提示选择更大尺寸，避免裁掉边缘。图片仍使用 PNG 1x / 2x / 3x。
- **连续操作和升级**：测量时排除旧 Slice，防止画布不断增大；保留原选区。替换插件生成的旧按钮/底色切片，保留手工 Slice。被新图标切片取代的按钮或矢量碎片导出设置会停用，原设置记录在文档插件数据中，并可随本次操作撤销，避免蓝湖出现重复按钮资源。

## 图层整理与画面保护

可以分别选择规范默认名称、清理安全空组、按阅读顺序排序、自动重新分组。默认名包括中文“备份”后缀；保留已有业务名。候选组主要依据背景包围、对齐、间距、现有文字和图层类型。

常规分组会检查包含阴影与描边的绘制范围，保留重叠关系。若只有保守的效果范围阻止完整卡片合并，插件会在内存中对比原生 1x、2x 渲染，并尝试有限个图层顺序位置。

“**优先完整卡片（允许极轻微阴影色差）**”默认开启：仅允许每次合并中不超过 0.05% 的像素出现最多 1/255 的 RGB 色差，透明度必须一致；结果会提示这类合并。关闭该选项时要求像素完全一致。超过阈值、无法验证或画板过大时，保留原结构，不强行合并。内存渲染不是 AI 分析，也不会写出用户切图文件。

纯规则无法保证理解任意业务组件树。跨父层散落内容、复杂交叠、锁定层、蒙版链、Stack / Smart Layout 和特殊混合模式仍可能需要手工调整。已有普通内容组不会被强行拆散。自动推断最多处理每个容器 500 个直接子层，保守排序和相邻分组上限为 300。

## 切片说明

- 在 Sketch 内创建真正的 Slice，设置“仅导出组内容”，关闭裁掉透明像素。
- 自动档将相近大小的图标归到标准尺寸，周边文字间距不足时可能降低档位。需要严格统一时可手选固定尺寸；放不下或与文字重叠的图标会被跳过并提示。
- 原始图片蒙版和裁剪结构按整体保留；不会把位图自动转换成纯矢量。
- 通用规则不能确定的图标，可将其完整组命名为 `icon/search` 等；不能可靠剥离的复杂背景仍需手动调整。
- 通过图层 ID 关联切片，重复执行会更新尺寸和格式，不叠加 Slice。手工切片不被覆盖。
- 蓝湖上传与网页下载尚未执行验收；已验证 Sketch 内的原生 Slice、SVG 画布、透明背景及导出内容。

## 验证

纯算法测试涵盖背景包围、单列/多列卡片、列表、最近邻配对、图标背景与碎片、绘制顺序、蒙版、微小像素差阈值。Sketch 原生测试验证五类布局、旧分组细化、切片升级、SVG 画布、画布尺寸更新、超尺寸保护、撤销、原生窗口和重复执行。

0.5.0 的真实设计稿在独立副本上验证：顶层 79 → 15，新增 24 组；五个导航项的图标文字成组，五块散落卡片底板归组。常规图标为 24 × 24 SVG，一个较大的装饰路径使用 32 × 32。原稿未修改；测试副本保存在本地 `evidence/private-v0.5.0/`，不会进入发行包。完整验证报告以 `evidence/` 中实际生成的 JSON 为准。

0.5.1 在真实设计稿副本中识别出 26 个候选资源，并验证：两个播放三角、点赞切片为 16 × 16 SVG；播放 SVG 只含白色三角路径；点赞切片与“98”不重叠。空间紧张的三处装饰或角标附近资源保留原切片并提示，其他切片正常更新或保留。1x、2x 画面像素保持一致。私有验证副本位于 `evidence/private-v0.5.1/`，不进入发行包。

规则测试与原生渲染检查不能覆盖所有设计稿。窗口已在 Sketch 内构建并截图检查；未完成鼠标点击的完整交互验收。

## 开发

源码无需构建即可作为 `.sketchplugin` 使用。

```sh
python3 scripts/test_native.py --node /path/to/node --python /path/to/python-with-Pillow
python3 scripts/package.py
```

测试需要 macOS、Sketch 和带 Pillow 的 Python，仅操作独立测试文档。`core.js` 为基础规则，`layout.js` 为布局推断，`regions.js` 为分组与绘制顺序，`glyphs.js` 为图标底色和碎片规则，`pixels.js` 为本地像素比较，`canvas.js` 为标准画布和文字避让，`progress.js` 负责文档级进度、普通事件循环、安全停止与运行状态，`engine.js` 负责 Sketch 操作，`dialogs.js` 负责窗口。
