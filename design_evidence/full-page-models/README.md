# 平台介绍页：蓝湖 / GPT-5.6 Sol / GPT-6 完整页面对比

预览地址：`http://127.0.0.1:8767/?case=full-page-models`

## 实验条件

- 蓝湖画板：`平台介绍页`，375 × 812。
- 固定快照：`da6dd92db9b6df7fc3fc4d2bc873e0ee`。
- 固定版本：`d4d1c235-1fb2-4395-9d0e-a5055d074f4e`。
- GPT-5.6 Sol high 与 GPT-6 high 分别在隔离输入下完成首版。
- 两份实现均在 Flutter 首次有效渲染前冻结，未根据截图修正。
- 两边使用同一组 11 个蓝湖原始切图；卡片、文字、渐变、阴影和交互为实时 Flutter。

第一次测试工具运行在默认 800×600 视口，固定页面被测试视口约束，尺寸断言在截图之前终止；调整测试视口为 375×812 后得到第一份有效 4× 渲染。模型源码没有因此改动。

## 结果

4× RGB MAE（0–255，越低越接近，不是还原度百分比）：

| 区域 | 5.6 R0 | 5.6 R1 | GPT-6 R0 | GPT-6 R1 |
| --- | ---: | ---: | ---: | ---: |
| 完整页面 | 4.0372 | 6.7949 | 4.4477 | 6.5204 |
| 排除共享切图后的原生结构 | 4.2043 | 7.5135 | 4.4760 | 6.9013 |
| 顶部首屏 | 2.1048 | 3.8028 | 2.9432 | 3.9471 |
| 平台能力 | 5.9004 | 10.2161 | 6.1340 | 10.3259 |
| 创作者收益 | 6.1941 | 10.0389 | 6.6180 | 9.0928 |
| CTA | 2.3305 | 3.9624 | 2.3305 | 3.9624 |

R0 样本中 GPT-5.6 Sol 的整体和各主要区域 MAE 略低。R1 在 4× Flutter 测试渲染器中出现回归：两个模型移除已打包的 `SourcePingFang` 后，测试环境没有可用中文回退字体，正文变成方框；扩大带透明留白的切图也增加了像素差，因此 R1 的所有区域 MAE 都变高。该结果按一轮修正规则原样保留，没有继续修改。

Web release 的表现与测试渲染器不同：浏览器具备中文系统字体回退，R1 文案可以正常显示，扩大后的徽章和收益图标也更接近原稿。页面因此保留 R1 供直接视觉判断，同时明确提示 R1 MAE 包含测试渲染器的方框字形，不能把这组数字直接当成 Web 视觉质量结论。

这轮回归说明视觉修正流程需要增加两个门禁：修改字体前先验证目标渲染环境的字形覆盖；修正后对关键区域做像素回归，指标变差时拒绝替换基线。共享主视觉和图标资源对整页 MAE 有显著贡献，因此报告仍同时展示排除资源矩形后的原生结构指标。
