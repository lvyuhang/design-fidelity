# GPT-5.6 Sol 多组件首版对比

预览入口：<http://127.0.0.1:8767/?case=model-comparison>

本实验让 `gpt-5.6-sol`、`high` 在隔离任务中直接读取既有蓝湖证据，分别实现图文动态卡片、评论、弹窗、底部导航、处罚申诉卡片、登录按钮与协议。三个源码文件在首次成功渲染前冻结，视觉修正次数为 0；性别选择沿用上一轮同协议的独立实验。统一页面提供原稿、5.6 首版、此前 GPT-6 已核对实现三列对照，也可单看任一实现或用滑杆叠加原稿。

此前 GPT-6 列经过核对和修正，而 5.6 列是冻结首版，因此结果用于观察工作流效果，不是严格的模型排行榜。

## 首轮结果

| 组件 | 5.6 Sol MAE | 此前 GPT-6 MAE | 计量区域 |
| --- | ---: | ---: | --- |
| 图文动态卡片 | 1.3621 | 0.4245 | 排除照片和头像 |
| 评论与嵌套回复 | 5.8565 | 1.3574 | 排除三个头像 |
| 清除缓存弹窗 | 3.7643 | 0.9301 | 完整 375 × 280 舞台 |
| 五项底部导航 | 4.7178 | 0.7412 | 完整 375 × 98 舞台 |
| 处罚申诉业务卡片 | 4.9574 | 1.3476 | 完整 375 × 125 舞台 |
| 登录按钮与协议 | 9.7899 | 1.0925 | 完整 375 × 395 舞台 |

指标是 4× 同网格 RGB 平均绝对误差，范围 0–255，不转换成“还原度百分比”。5.6 的若干固定文本框高度或宽度不足，在 Flutter debug 测试引擎中触发黄黑溢出诊断条；这些像素被保留并计入指标，因为它们暴露了真实约束风险。Web release 不显示诊断条，所以指标不能直接当作浏览器视觉差异。动态图照片、动态图头像和评论头像使用同一份蓝湖预览裁切，独立指标排除这些区域。导航消息图标缺少源路径，两种实现均为近似绘制。登录原稿区域导出为 1329 × 1400，评估仅按 375 × 395 逻辑网格重采样到 1500 × 1580，没有坐标拟合。

## 冻结与可复现证据

- `social_sol56.frozen.dart` / `social-freeze.json`：图文动态与评论。
- `utility_sol56.frozen.dart` / `utility-freeze.json`：弹窗、导航、申诉。
- `login_sol56.frozen.dart` / `login-freeze.json`：登录与协议。
- `*-protocol.json`：隔离输入与禁止项。
- `*-sol56-4x.png`、`*-gpt6-4x.png`：Flutter 测试引擎 4× 渲染。
- `evaluation.json`：完整区域、局部区域、资源缺口和哈希。
- `source-sol56-gpt6.png`：六类组件三列静态总览。
- `first-render-test.log`：冻结后的首次完整渲染测试。

评论源码最初冻结后在首次编译阶段发现一个 `const RichText` 语法错误；它还没有产生截图。唯一修复是移除外层 `const`，没有改变尺寸、样式、文字或回调，随后同步更新冻结副本和哈希。这项修复记录在 `social-freeze.json`。

浏览器验收覆盖 7 类组件切换、三版对照、两种单列模式、两种透明叠加、评论回复回调和性别两个状态；浏览器错误及警告日志为空。
