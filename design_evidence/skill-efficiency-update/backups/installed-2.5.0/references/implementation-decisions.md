# 节点实现决策

在编码前为每个可见叶节点选择实现方式。选择依据是 MCP 原始证据，不是节点名称、截图观感或开发者对常见组件的记忆。

## 决策表

| 源证据 | 实现方式 | 禁止行为 |
| --- | --- | --- |
| 可导出的位图、SVG 或完整资源 bundle | 安装并使用原始资源；保留透明画框、裁剪和缩放方式 | 用系统图标、emoji、CSS 形状或手绘近似替代 |
| 通用界面矢量，且具有完整 `bounds`、路径/点、填充或描边、线宽、端点和连接样式 | 按源数据精确绘制；路径坐标由源画框转换，不增加视觉补偿 | 根据截图估算尺寸、改用框架自带 icon、手调到“差不多” |
| 定制头像、照片、插画、印章或业务图标，没有可复用原始素材 | 在源画框内使用保形“未切图”占位，并登记排除原因 | 根据零散轮廓或业务语义仿造图形 |
| 独立装饰节点，如下划线、色带、引号底板、分隔线 | 按独立节点实现和验收 | 合并进相邻文字样式后遗漏，或认为面积太小可忽略 |
| 阴影、发光、模糊、渐变或透明叠层 | 使用源效果参数；若 MCP 表达不完整，以参考图采样恢复强度和衰减并记录限制 | 只给通用 `BoxShadow`，或用整页 MAE 判断已一致 |
| 证据不足且无法确定属于哪类 | 保留源画框，标记未实现原因并补取证 | 自行猜测素材类型和形状 |

`asset_id` 缺失只说明没有直接资源引用。有可取得的完整原始 SVG/bundle 时仍使用该资源；没有资源时继续检查路径、填充、描边和效果字段。零散路径不能作为重建定制业务素材的依据。

## 几何映射

- Widget 或绘制画布的逻辑尺寸先匹配源 `bounds`，路径再在该画框内转换。不要先选一个方便的整数尺寸再缩放路径。
- 归一化点使用 `x * width`、`y * height` 映射；保留源线宽、颜色、`strokeCap`、`strokeJoin` 和闭合方式。
- 有贝塞尔控制点、旋转/翻转、复合路径、填充规则或祖先裁剪时，必须完整转换；不能只连端点或仅复制 bounds。无法处理时报告缺失能力并占位。描边可能伸出路径画框，检测 ROI 应含外扩墨迹，不能人为裁掉以让 bbox 相等。
- 元素位置来自源画框及父级坐标。不要依赖 Row/Column 的默认基线、内边距或图标字体画框来推断视觉中心。
- 原始资源可能有透明边距。布局对齐看源画框，视觉验收同时看非透明像素边界和图文关系。
- 占位外形匹配源素材：圆形头像使用圆形，圆角卡片图标使用对应圆角，印章按原外形；占位不能改变相邻布局。

## Flutter 落地

- 精确小矢量优先使用尺寸固定的 `CustomPaint`/`CustomPainter`，画布尺寸等于源画框。不要使用 `IconData` 替换设计路径。
- 路径数据、线宽和颜色集中为源节点常量或生成数据，并保留 `node_id` 映射，避免散落魔法数字。
- 对需要像素验收的元素避免框架默认最小触控尺寸、额外 padding、IconButton 约束和主题颜色注入；交互热区可以包在视觉元素外层。
- 阴影测试必须启用生产阴影。Web 交付还需在实际浏览器渲染器检查一次，不能只看 Flutter widget test 截图。

## 缺图与效果的验证边界

缺图色块不可能与原照片像素一致。主契约保持原参考图并精确排除素材内部；另用 Widget 测试断言占位画框和裁剪形状，或建立明确标注的合成占位测试契约，验证圆形/圆角及提示文案。不要改原参考图，也不要把“占位测试通过”表述为“素材还原通过”。默认粉色色块、描边与语义提示来自 Skill 规则，外形尺寸来自源节点。

效果可能挂在父组而不是叶节点。初始化器的 `effect_candidates` 会提示已知字段中的启用效果，但不保证识别所有 MCP schema；仍需审核祖先样式、蒙版、层叠与裁剪。阴影缺失时依次检查：源效果是否读全、代码是否实现、祖先是否裁剪/遮盖、测试环境是否关闭阴影、模糊半径单位与 DPR 是否一致，再考虑根据参考图采样校准。推导出的效果参数需标记为参考图校准，不能声称由 MCP 精确提供。

## 验收闭环

1. 整页或组件 region 检查整体结构。
2. 每个小型高显著叶节点使用 `small_visual` 检查 bbox、中心、宽高、边缘、墨迹比例与轮廓重叠；必要时检查颜色。
3. 图标与文字、卡片与日期、标题与装饰等组合增加 relation 检查。
4. 阴影/渐变沿衰减方向布置多个颜色采样点。
5. 最后查看原稿与实现并列图。肉眼发现但契约未失败的差异代表契约漏检，应先补检查再修代码。

调试顺序采用“证据缺失 → 节点缺失 → 画框 → 路径/素材 → 组内关系 → 颜色 → 效果衰减”。每轮只修改已定位的误差类别，保存独立输出和报告，避免同时改动多个层面后无法判断原因。
