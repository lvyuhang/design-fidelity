5.6 Sol 对女生选中图标和角标的素材选择、尺寸与坐标非常准确。未选卡片使用常规 `BoxShadow`；卡片填充只有 30% 不透明度，阴影因此透进卡片内部，产生明显暖色染色。固定宽文本没有显式清除主题字距，测试渲染中出现黄色溢出标记，标题、选项文字和警示文字的局部误差随之升高。背景光晕采用了简化透明度且没有源高斯模糊，也贡献了差异。

这些是冻结首版的真实结果，没有据此修正代码。它说明单纯提供 MCP 参数和原始切图仍不足以保证 Flutter 的透明合成和文字约束自动正确；选中态因为卡片是不透明填充，标准阴影的内部染色被遮住，结果明显更接近。

## 公平性边界

两种首版使用相同的 375×350 源区域、两张原稿、字体文件、五份原始导出资源、4× 测试渲染器和区域坐标。女生选中态对所有实现统一排除 `(295,299,37,34)` 的盾牌区域作为共同指标；全画布和盾牌诊断仍保留该差异。

这不是严格的模型排行榜。5.6 Sol 被隔离于现有实现和指标，但能查看原稿 PNG；GPT-6 首版来自持续会话，已经掌握半透明外阴影、显式字距和背景模糊映射等经验，因此输入上下文并不对称。每个模型只有一次实现、两个固定状态，不能推断总体模型胜率。

右侧淡色盾牌的内部布尔填充没有 points 或导出资产。5.6 Sol 和 GPT-6 首版都只绘制可用外框与勾，没有使用原稿裁切；校准版使用原稿裁切，其低误差不能作为独立绘制证据。
