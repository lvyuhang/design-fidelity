已落实的改动

  1. 默认保形缺图占位；禁止把业务卡片、导航与文字合成裁图当作组件实现。编译期拦截文字及其祖先的默认 render_fallback。
  2. 同类语义按组审核，声明展开成逐节点检查；覆盖和阈值不减少。源单色文字自动生成待审检测器，异常仍需源图复查。
  3. 冻结前只用原稿测试检测器，不等 Flutter 渲染后再发现无墨迹；源图预检不能自动证明目标层正确。
  4. 固定 Python，计阶段墙钟，跨基线聚合不可变 run.json；归档日志不能重置轮数。

下一次页面的验证口径

从开始取证到可打开预览计总墙钟，分 evidence / implementation / validation / preview / infrastructure。报告全部尝试、基线、缺素材数量和真实代码范围。2–3 轮为目标，不承诺固定分钟数。先确认业务 UI 为组件代码，再比较速度和还原度；裁片占比高的旧页面不能作为同质量速度基准。
