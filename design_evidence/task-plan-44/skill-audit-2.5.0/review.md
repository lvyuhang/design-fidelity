# Skill 2.5.0 复核结果

日期：2026-10-13。对象：lanhu-design-fidelity 2.4.0 → 2.5.0。

## 发现与优化

| 发现 | 优化 | 验证 |
| --- | --- | --- |
| 小图标的尺寸和墨迹检查只写在文档里，脚本允许漏配 | 新增 small_visual profile，要求单节点和完整几何/墨迹/轮廓阈值 | 缺阈值、整行替代单节点均返回 NOT_EVALUATED |
| 同边界、同中心、同墨迹量的错误路径可以通过 | 新增源坐标下的 mask IoU loss | 反向斜线旧检测通过、新检测失败；正确路径通过 |
| 阴影可能在父容器，叶节点清单无法发现 | 初始化器输出启用效果候选，补充人工审核范围 | 父组启用阴影进入清单，禁用效果不进入 |
| 占位色块不能与原照片直接比较 | 明确独立 Widget 测试或合成占位契约 | 正确圆形通过，矩形替代失败 |
| 规则重复，缺一份素材可能被解释为停止整页 | 合并入口规则，按需加载细节；仅阻塞缺失素材，继续其他部分 | 文档交叉复核 |
| 检测报告写死旧版本 2.0.0 | 从 Skill 元数据读取版本 | 本次报告正确显示 2.5.0 |

## 仍然需要人工判断的范围

节点分类、复杂矢量完整性、MCP 未知字段、检测器 ROI 与阈值校准、参考图效果推导仍需审核。脚本没有自动证明所有可见节点都被正确分类，也没有验证未知页面或任意模型的一次生成效果。

本次没有新增业务页面或重新编译 Flutter。优化目标是让已发现问题成为可重复执行的检查，减少后续遗漏与无效重试。
