# 5–10 分钟首次页面交付：候选流程

本轮验证的是流程原型，尚未完成全新页面的 5–10 分钟前瞻验证。暂不将该目标描述为已实现，也不替换正式 Skill 的质量规则。

## 已核实的瓶颈

上一轮新页阶段（13:46:45–14:09:20）发生 93 次模型工具调用和 93 次返回，序列化工具返回约 2.26 MB。正式渲染与门禁只需约 1.8 秒；主要成本是取证传输、临时脚本编写、完整 JSON 回显和多次修补脚本。

171 个节点的 snapshot 实际为 overview 索引；46 个文本节点均无 raw_style/font 或 text_spec。节点计数齐全不等于完整样式证据齐全。不能再以这些计数证明取证完整，也不能自动从参考图占比最大的颜色认定文本颜色。

`1备份36` 复用了上一页主体，不是独立新布局样本。上一轮 29.1% 仅是两个选定阶段时长的算术差，不能作受控提速结论。22 分 35 秒截止于正式构建，未含后续浏览器确认、统计、文档、旧页回归及最终回复。下一轮同时记录用户等待的总时长与各阶段时长。

原报告的“有效新增 token”是自定义的非缓存输入加输出数；缓存 token 仍须单独记录，不代表免费，也不能用于直接推导费用。

## 候选执行路径

| 阶段 | 时间预算 | 输入与输出 | 模型往返目标 |
|---|---:|---|---:|
| 固定画板、取证与预检 | 0–2 分钟 | 节点索引、完整样式/父级效果、参考 PNG、原始资产、字体字符覆盖；输出紧凑缺口摘要 | 3–4 |
| 实现及验收配置 | 2–5 分钟 | 复用现有 Flutter 画布、文本/缺图基础组件、渲染测试与验收模板；仅配置页面差异 | 3–5 |
| 首轮渲染与定向修正 | 5–8 分钟 | 一次完整门禁，只返回失败 ROI；看原稿与实现并列图，集中修改真实差异 | 3–5 |
| 最终构建与交付 | 8–10 分钟 | 门禁、交互、静态检查、最终一次 Web 构建、浏览器确认与短日志 | 2–4 |

时间和调用数是预算，不能作为跳过检查或强制宣布通过的条件。简单页目标 5 分钟，常规页上限目标 10 分钟。复杂插画、异常证据或 SDK 环境问题需明确标记原因及已用时。

## 必须改变的动作

1. 完整 MCP 响应留在工具执行层并落盘，仅向模型返回布局/文字/资产摘要、缺口和文件路径。图片仅展示整页参考及失败区域；不回显 base64、完整 manifest 或数万字门禁报告。
2. overview 用于定位和盘点；实现样式来自 inspect 数据。拿到 snapshot 后，独立区域读取可在同一工具调用内有界并发。样式缺口要在编码前暴露。
3. 传输失败一次即按错误类型切换方式。优先客户端可用的文件/资源交付；若为 JSON，可在函数执行层直接调用文件工具保存，避免经模型重写 JSON。校验字节/哈希后再使用。
4. 编码前对完整源文本做字体 cmap 预检，包含新增文案。需要扩充时保留已交付页面的字符集合；禁止通过字体替换消除缺字。
5. 一个通用运行器服务所有页面，不再为每页复制预检、计时、日志和构建脚本。项目/Skill工具维护成本独立记录，不能混进单页后再将它描述为正常还原时间。
6. 契约模板只提供候选，按本页源节点、文字样式、资产 SHA 和几何确认映射；新增图标、独立装饰、父级阴影必须审核。禁止将旧页面位置/颜色无条件套用。
7. 每次迭代可以直接跑完整门禁：当前仅约 0.3 秒，没有必要为省这点时间建立复杂的局部门禁调度器。给模型的反馈只保留失败项与局部图。
8. 固定门槛后最多两轮集中修正作为正常预算；仍未通过时如实标记，不放宽门槛、不扩大遮罩。交付前必须看一次最终并列图。
9. Web release 只在最终交付时构建。静态分析使用项目已证实可用的 Dart 分析命令，不在每一轮重复触发已知崩溃的 Flutter analyzer。

## 本轮已经落地并测试

通用运行器：`tools/fidelity_fastlane.py`。契约只读；前置字体、文件哈希、原生参考分辨率和资产解码检查通过后才启动渲染。保留正式收据和完整日志，向模型仅输出状态、耗时和报告路径。运行器不宣称自动审核完整样式或所有视觉语义。

- `1备份36`：预检 + 渲染/交互 + 原门禁 + 静态分析共 **3.846 秒**，MAE 3.27、P95 12，原门禁 PASS_WITH_EXCLUSIONS。
- `1备份34`：预检 + 渲染/交互 + 原门禁共 **2.440 秒**，PASS_WITH_EXCLUSIONS。
- 故障注入：删除字体中的“折”，预检即阻断；篡改实现文件哈希，预检即阻断。都不会先渲染再发现问题。
- 以上均为已有页面验证，不计作首次实现提速证据。

调用示例（在项目根目录，输出目录必须全新）：

```sh
.venv-fidelity/bin/python tools/fidelity_fastlane.py \
  --contract design_evidence/message-backup-36/visual-contract.json \
  --app flutter_ui_components \
  --test test/message_backup_36_render_test.dart \
  --output-env MESSAGE_BACKUP_36_RENDER_OUTPUT \
  --output design_evidence/fastlane-exploration/next-run \
  --analyze lib/experiments/message_backup_34_page.dart lib/experiments/message_backup_36_page.dart
```

最终交付加 `--build`；每个页面只需参数与自身 Flutter 测试，不需复制运行器。
